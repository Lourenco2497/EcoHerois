# Eco Heróis

Jogo web educativo sobre ambiente e sustentabilidade, desenvolvido no âmbito da licenciatura.

## Sobre o projeto

O **Eco Heróis** é um jogo interativo com 5 níveis progressivos que ensina conceitos de ecologia e sustentabilidade de forma lúdica. O jogador aprende sobre reciclagem, poluição e boas práticas ambientais enquanto avança nos desafios.

## Estrutura

```
├── index.html        # Página inicial
├── learn.html        # Área de aprendizagem
├── tutorial.html     # Tutorial do jogo
├── sobrenos.html     # Sobre nós
├── nivel1.html       # Nível 1
├── nivel2.html       # Nível 2
├── nivel3.html       # Nível 3
├── nivel4.html       # Nível 4
├── nivel5.html       # Nível 5
├── estilos.css       # Estilos globais
├── imagens/          # Recursos visuais
├── sons/             # Efeitos sonoros
└── videos/           # Vídeos
```

## Tecnologias

- HTML5
- CSS3 (Bootstrap 5)
- JavaScript (vanilla)

## Como jogar

Abre `index.html` num browser e segue as instruções do tutorial.
